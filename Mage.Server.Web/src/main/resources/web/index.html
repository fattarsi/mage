Keyboard

F2 pass priority · F3 stop skipping · F4 next turn · F5 next main · F6 end of turn · F7 your next turn · F9 resolve stack

Card & player icons

💤 summoning sickness (can’t attack/tap yet) · 👑 monarch · 💀 out of the game · green ring = playable now · gold ring = valid target · orange ring = eligible attacker/blocker

Phase bar & skips

The top bar is the turn loop (current phase green, breakpoints red). Click a main/attack/block phase to set a breakpoint. Skip buttons are sticky: they pause for responses and resume when the stack clears. Run to breakpoint appears once you set one.

Arrows

red = attacker → defender · blue = blocker → attacker · purple = spell/ability → its target
Card sizes are in the right column ▸
Tap a card to use it (play, tap for mana, attack, use ability). Press & hold to preview — holding never plays anything.
Where the game hands you priority so you can act. “Every step” guarantees you can always respond; use the skip buttons (Next turn, Resolve stack, etc.) to jump ahead when you don’t need to. Declare-attackers/blockers always stop regardless.
